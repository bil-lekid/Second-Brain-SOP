# Tujuan
1. Admin membuat penawaran harga, sales mengirimkan penawaran harga ke customer.
2. Semua data penawaran harga tercatat.
# Langkah
1. Manajer memberikan data penawaran harga *customer* ke admin
2. Data berbentuk tabel nama barang, jumlah barang, harga jual, harga beli, dan apakah harga beli termasuk ppn (ditulis ppn). 
3. Buka aplikasi PPP v0.2.xlsm (lokasi folder di: `D:\\OneDrive\\PPP\\Sales\\Quotation`)
4. Buka database (lokasi folder di Notion: `D:\\OneDrive\\PPP\\Sales\\Quotation`)
5. Ganti nomor PH untuk membuat PH baru.
6. Ganti customer sesuai dengan instruksi *manajer*.
7. Ketik semua nama barang, jumlah, unit, harga satuan, harga beli, dan ppn.
8. Apabila semua barang sudah dimasukkan dan sudah dicek kembali, tekan "*save to database*" untuk menyimpan data ke database.xlsx.
9. Tekan tombol "*save to excel and pdf*" untuk menyimpan file berformat .xlsx dan .pdf. File akan disimpan pada folder *customer* sesuai dengan PH yang dibuat.
10. Double check lagi, apabila ada kesalahan maka perbaiki dan ulang step 8 dan 9.
11. Kirim penawaran harga PDF ke *Manajer/sales*.

# Langkah Revisi Penawaran Harga
1. Cari dan buka excel dengan nomor PH yang ingin direvisi.
2. Perbaiki kesalahan pada penawaran harga 
3. *”Save to database”* dan hapus data lama untuk digantikan data baru.
4. Jangan gunakan ”*save to excel and pdf*”. Print to pdf dengan format nama sebagai berikut: `tanggal` quotation - PH `nomor_PH-nomor_revisi` contoh 260904 Quotation - PH BI2609012-1 untuk menandakan revisi pertama untuk penawaran harga nomor BI2609012 pada Tanggal 4 September 2026.
5. Kirimkan revisi penawaran harga ke manajer/sales.

Note:
1. Apabila PH **ingin dijadikan satu halaman**, bisa gunakan step berikut:
	1. Pada aplikasi PPP v0.2.xlsm, sheet *Quotation2,* tekan ctrl + P.
	2. Pada *setting* ganti *No Scalling* menjadi *Fit Sheet on One Page.*
	3. Tekan esc.
	4. Tekan tombol *"save to excel and pdf"*.
2. Untuk harga repeat diberikan tanda ® pada nomor untuk quotation2, dan untuk quotation meiloon cukup diketik harga repeat pada note.
3. Untuk customer Meiloon khusus pakai sheet quotation mei. Ada kolom spesifikasi dan setiap note dituliskan di kolom terpisah.
4. Untuk memberikan gambar bisa langsung di bawah nama barang dengan kolom dibesarkan, atau bisa pada halaman lampiran baru.
